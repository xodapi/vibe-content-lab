**Vibe Content Lab**

## Подзаголовок

Показывает весь путь прикладного AI-инструмента: источник → поиск → ответ с
цитатами → оценка качества → контролируемое действие.

## Как это работает

1. **Берём только публичный источник.** В базу попадает документация Agent API,
   без корпоративных данных, пользовательских переписок и ключей.
2. **Готовим поиск.** Документ делится на смысловые фрагменты, для них строятся
   embeddings и локальный индекс Chroma.
3. **Отвечаем с опорой на источник.** Интерфейс возвращает найденные фрагменты, а
   не выдаёт догадку за факт. Если данных нет, правильный ответ — «в документации
   этого нет».
4. **Проверяем качество.** Небольшой versioned набор вопросов измеряет Hit@4 и
   MRR@4. Перед релизом его нужно расширить реальными вопросами пользователей.
5. **Не совершаем платное действие молча.** Для генерации сначала запрашивается
   бесплатная смета, затем оператор подтверждает стоимость и только после этого
   запускается запрос.

## Технический контур

FastAPI · React · Chroma · OpenAI embeddings · Docker Compose · n8n · Dify Cloud ·
pytest · Ruff · HMAC webhooks · SQLite audit trail

## Безопасность

- ключи не попадают в браузер и Git;
- у API-ключа только необходимые scope, IP-ограничение и лимит расходов;
- повторяемые действия используют idempotency key;
- подпись webhook проверяется HMAC;
- любые списания требуют явного человеческого подтверждения.
