# Dify Cloud: preparation and evidence

Use the free **Sandbox** plan. This project uses only the public documentation URL:

`https://lk.vibemarketolog.ru/docs/agent-api`

It is an independent technical lab, not a VibeMarketolog product or affiliation.

## Build the application

1. In **Studio**, create a **Workflow** named `Vibe API Documentation Assistant`.
2. Under **Knowledge**, create the dataset `VibeMarketolog public Agent API`.
3. Add the public documentation URL above as a website source. If the workspace does
   not offer URL import, upload a document generated by:

   ```bash
   python -m rag.export_dify_source
   ```

4. Add nodes in this order:

   ```text
   Start(question: paragraph, required)
       → Knowledge Retrieval(dataset: VibeMarketolog public Agent API, Top K: 4)
       → LLM(system prompt: system-prompt.md)
       → End(answer)
   ```

5. In the LLM node insert the retrieval result variable into the prompt. Select a
   built-in trial model while Sandbox credits remain. Do not copy any Factory
   credentials into Dify.
6. Publish only after the evaluation cases in `test-cases.md` pass. Keep the app
   private while it is a portfolio demo.

## Evidence to retain

Create `evidence/` locally after actual execution. Do not fabricate files before it.

- `knowledge-base.png`: source and indexing status;
- `workflow-canvas.png`: four-node canvas;
- `run-01.png`, `run-02.png`, `run-03.png`: representative cited answers;
- `execution-log.png`: successful workflow execution;
- `evaluation.md`: outcomes for all test cases.
